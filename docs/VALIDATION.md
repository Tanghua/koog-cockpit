# 验证口径

## 原车机 0.3.0 验收

- Android 13 实机已验证真实麦克风采集及非零音量反馈。
- 合成中文音频样本已跑通识别、客户端工具请求、本地 Koog 执行、真实 MediaX 回执及原生回复音频写入。
- 播放、暂停及查询状态已验证；回复曲名与实际媒体快照一致。
- 在隔离现场收音的样本测试中，额外保持 30 秒后连接正常，并验证收音恢复。
- 新版媒体页的主要按钮完整可见，页面未处理 JavaScript 异常为 0。

样本测试通过真实语音服务和原生通道，不伪造识别或设备结果。它不等于真人远场、行驶噪声、长时间稳定性或现场听音验收。原始实机日志、录音、设备标识和私人部署配置未上传。

## 本仓库整理差异

仅保留 Koog 所需模块；添加可独立使用的 npm 锁文件及 Gradle Wrapper；移除固定部署地址，改为本地配置和可选构建属性。Android 端 Koog 仍使用固定提案执行器，未新增云端模型客户端或本地模型。

原车机安装包的声音与本地能力验收不能自动证明在另一台设备上同样有效。新设备须配置语音网关，并确认厂商媒体及地图服务兼容。

仓库构建结果记录在 `BUILD-VALIDATION.md`。测试针对 Koog 框架与宿主行为，不代表大模型规划质量。
